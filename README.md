# 緋紅世紀 Crimson Century

原創轉珠戰鬥遊戲（HTML5），角色／美術／文字為原創；背景音樂採用 Kevin MacLeod（incompetech.com）創作並依 CC BY 4.0 授權使用。

- 遊玩：https://allen640107-gh.github.io/crimson-century-web/
- 6×5 珠盤、轉珠戰鬥、5 人隊伍與隊長技、40 關卡／5 章
- 屬性剋制：火→木→水→火、光⇄暗
- 存檔：localStorage `crimson_save_v1`
- 難度模擬：`node tools/sim.js`
